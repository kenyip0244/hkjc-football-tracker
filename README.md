HKJC Football Match Results Tracker & Half-Time Filter Web App
一個專為香港賽馬會（足智彩）及各大足球聯賽設計的半場/全場賽果追蹤與過濾 Web 應用程式。
🌟 主要功能特點
半場比數快速過濾：
一鍵篩選 1:0 / 2:0 / 0:1 / 0:2 組合
支援個別半場比數（1:0、2:0、0:1、0:2、0:0 等）過濾
多維度賽事管理：
支援聯賽分類篩選（歐霸盃、歐協聯、英超、西甲、沙特聯等）
即時關鍵字搜尋（隊名、球賽編號如 FB3257）
雙視圖介面：
現代深色科技風「卡片檢視 (Cards View)」
數據一目了然「表格檢視 (Table View)」
數據統計概覽：
總記錄場次、符合篩選場次、半場領先勝出轉換率、平均總入球數
本地儲存與資料匯出：
支援自訂新增賽事，資料儲存於瀏覽器 LocalStorage
一鍵匯出 CSV 檔案
零依賴 (Zero Dependency)：
純原生 HTML5 / CSS3 / JavaScript，可直接部署在 GitHub Pages。


🚀 GitHub Pages 5 步極速部署指南
建立 GitHub Repository：

登入 GitHub，點擊右上角 New repository。
命名為例如 hkjc-football-tracker，設為 Public。

上傳程式碼：

將 index.html 及 README.md 上傳到該倉庫的主分支（main）。

開啟 GitHub Pages：

進入該 Repository 的 Settings -> Pages。
在 Build and deployment 下方的 Branch 選擇 main 分支與 /(root) 目錄。
點擊 Save。

完成部署：

等待約 1 分鐘後，即可透過專屬網址（例如 https://<你的GitHub用戶名>.github.io/hkjc-football-tracker/）直接在線訪問使用！
